Domínio prático de Box Model e Flexbox

Demonstração prática com 20 elementos configurados individualmente nas quatro camadas do Box Model (Content, Padding, Border e Margin) e organizados de forma responsiva com 20 propriedades de Flexbox.

Camadas do Box Model

Margin → Border → Padding → Content

01. Content Largura, altura e conteúdo interno
02. Padding Espaçamento entre conteúdo e borda
03. Border Espessura, estilo e cor do contorno
04. Margin Distância externa entre elementos

flex-direction: row

Distribui os itens horizontalmente no eixo principal.

justify-content: space-between

Alinha extremidades e distribui o espaço livre igualmente.

order & align-self

Controle individual de ordem visual e alinhamento transversal.

flex-wrap: wrap

Permite quebra automática de linha em telas menores.

CSS Externo (<link>)

Separação limpa entre estrutura HTML5 e regras visuais reutilizáveis.

Seletores Class e ID

Classes para padrões compartilhados e IDs para elementos exclusivos.

Gap, Row-Gap e Column-Gap

Espaçamento consistente entre linhas e colunas sem margens extras.

Flex Shorthand (flex: 1 1 260px)

Combina crescimento, encolhimento e tamanho base responsivo.

Layouts Responsivos Mobile & Desktop

Redimensione a janela do navegador para observar a adaptação automática dos containers Flexbox.
